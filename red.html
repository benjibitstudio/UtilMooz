Herramientas de red online

Utilmooz ofrece diferentes herramientas gratuitas para trabajar con direcciones IP, subredes, DNS, dominios y URLs directamente desde el navegador.

¿Qué herramientas de red podés utilizar?

Podés consultar tu IP pública, convertir direcciones IPv4 a decimal o binario, convertir números decimales a IPv4 y calcular información de redes mediante CIDR.

También podés consultar registros DNS, servidores MX, registros SPF y DMARC de un dominio.

La herramienta URL Parser permite analizar diferentes partes de una dirección web, incluyendo protocolo, dominio, puerto, ruta, parámetros y fragmentos.

Calculadora de subredes CIDR

La calculadora de subredes permite obtener la dirección de red, máscara, dirección de broadcast, cantidad total de direcciones y cantidad de hosts utilizables.
